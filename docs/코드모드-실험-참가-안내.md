# Code Mode 비교 실험 참가 안내

평소처럼 Claude Code(터미널)로 K-System MCP 화면 개발을 하시면 됩니다.
매일 아침 Code Mode가 자동으로 켜지거나 꺼지고, 사용 지표(숫자)는 매일 16:55에 자동으로 보내집니다.
16:55에 Claude Code가 꺼져 있으면 다음에 실행할 때 보내집니다.

- 기간: 2주 (    월    일 ~     월    일)
- 문의: (담당자)

## 설치 (1분)
1. 받은 `codemode-ab-install.cmd`를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누른 뒤 "실행"을 누릅니다.
2. 이름을 입력하면 끝납니다.

## 사용
- 터미널(Windows Terminal 또는 PowerShell)에서 평소처럼 `claude`를 실행합니다.
- 화면 위에 **노란 안내**("오늘은 Code Mode 켬 날입니다")가 보이면 `/exit` 후 `claude`를 한 번 더 실행합니다. 전날부터 켜 둔 창에서 주로 나옵니다.
- Code Mode가 처음 켜질 때 "Yes, turn on Code Mode" 확인 창이 나오면 승인합니다.

- 세션 중간에 `/model`로 모델을 바꾸지 말아 주세요. 사용 모델: (          )
- Code Mode가 켜졌는지 보고 질문 방식을 바꾸지 말고 평소처럼 써 주세요.

## 확인 명령
- `/ab-status`: 오늘 배정과 오늘 집계
- `/ab-report`: 지금까지 결과를 바로 전송

## 보내는 내용
날짜, 모드, 세션 수, 질문 수, API 왕복 수, 토큰 수, 도구 호출 수, 응답 시간뿐입니다. 대화 내용, 화면명, ERP 데이터는 보내지 않습니다.

## 실험이 끝나면 (제거)
`%USERPROFILE%\.claude\mods\codemode-ab\scripts\uninstall.cmd`를 더블클릭하면 매일 작업, 모드, 설정 항목이 모두 지워집니다.
