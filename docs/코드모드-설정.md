# Code Mode 설정 (공식 실험 기능)

- 버전: Claude Code v2.1.323 이상
- 켜기: `~/.claude/settings.json`의 `env`에 `"CLAUDE_CODE_EXPERIMENTAL_CODE_MODE": "1"` (프로젝트 설정 파일에 넣으면 무시됨)
- 처음 시작할 때 "Yes, turn on Code Mode" 확인
- 지원: 터미널의 대화형 `claude` 세션만. `-p`, VS Code, 데스크톱 앱, 클라우드 세션은 미지원
- 시작 안 되는 조건: API key helper, agent teams, OpenTelemetry 내보내기, DISABLE_TELEMETRY 설정, HIPAA/ZDR 조직, Bedrock 등 게이트웨이
- 끄기: 값을 `0`으로
- 공식 토큰 절감 수치 없음. 같은 작업을 켬/끔으로 실행해 `/cost`, `/context`로 비교 권장
- 출처: https://code.claude.com/docs/en/code-mode
